How to use

Same idea as the lunar-lander ship tracer: load a photo, mark the drawing box, click the left-wing outline, paste Swift into PogoWingOutline.left in WizardDiagrams.swift.

1. Load a side-view photo (pins down). A reference auto-loads from scripts/references/pogo-plug.png.
2. Set plug box: click the top-left, then bottom-right of the full plug (cable top through pin tips). That box is (0,0)–(1,1) in the Swift drawing.
3. Place / drag the left wing (closed outline). Click a segment to insert between those two nodes. Drag to move. Select a node, then Delete node, right-click, or ⌫.
4. Scroll zoom · Space+drag pan.
5. Copy Swift snippet and paste into App/Diagrams/WizardDiagrams.swift. The right wing is mirrored automatically.
6. Paste previous (or paste into the output box) reloads a prior Swift snippet or JSON export so you can keep editing.
